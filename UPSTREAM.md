# Upstream integrations

The canonical artwork, semantic inventory, resolver contract, previews, and
validation tools live in this repository. Consumer-specific integrations are
reviewed in their respective upstream projects:

| Project | Integration |
| --- | --- |
| OASIS STIX visualizer | [oasis-open/cti-stix-visualization#68](https://github.com/oasis-open/cti-stix-visualization/pull/68) |
| OASIS CTI documentation | [oasis-open/cti-documentation#140](https://github.com/oasis-open/cti-documentation/pull/140) |
| FreeTAXII graphics | [freetaxii/stix2-graphics#8](https://github.com/freetaxii/stix2-graphics/pull/8) |
| FreeTAXII gallery | [freetaxii/freetaxii.github.io#2](https://github.com/freetaxii/freetaxii.github.io/pull/2) |

The integrations use the immutable asset source at commit
[`58aad32c60c7b5150155c01ce83a07bb3408a172`](https://github.com/Kevinwochan/stix-2.1-community-svg-icons/tree/58aad32c60c7b5150155c01ce83a07bb3408a172).
Repository-specific tests, packaging, accessibility behavior, and licensing
notes remain with each pull request.
